# Notepad — Project Report

## Overview

This project extends the Notepad application built across Practices 5–8 with exception handling, a spell checker, and four optional features.

---

## Required Features

### 1. Exception Handling

An exception hierarchy is defined in `notepad_exception.h`:

- `notepad_exception` — base class, inherits from `std::runtime_error`
- `file_not_found_exception` — thrown when the file does not exist on disk
- `file_read_exception` — thrown when the file cannot be opened or read
- `file_write_exception` — thrown when the file cannot be written

Both `open_file()` and `save_file()` in `main_window.cpp` wrap their file operations in `try / catch (const notepad_exception&)` blocks and display errors via `QMessageBox::critical`.

The hierarchy allows all three exception types to be caught with a single `catch (const notepad_exception&)`, while still carrying a specific error message via `what()`.

### 2. Spell Checker

The spell checker is split across two files: `spell_checker.h` and `spell_checker_highlighter.h`.

**`spell_checker`** loads `data/words.txt` (370,105 lowercase entries) into a `std::set<std::string>` at startup. `std::set` was chosen over `std::vector` because its logarithmic lookup is fast enough to check every word on every keystroke without lag. Before looking up a word, it is lowercased and stripped of non-alphabetic characters by the `clean()` helper — this handles cases like `Hello`, `don't`, or `world.` correctly.

Spelling suggestions are generated by `suggestions()`, which searches the dictionary for all words within edit distance 1 of the misspelled word (one substitution, insertion, deletion, or transposition). Up to 5 suggestions are returned.

**`spell_checker_highlighter`** is a subclass of `QSyntaxHighlighter`. Qt calls its `highlightBlock()` method automatically whenever a paragraph changes. The method uses a regular expression to find all words in the paragraph and applies a red `SpellCheckUnderline` format to any word that fails the spell check.

Right-clicking anywhere in the editor opens a context menu. If the word under the cursor is misspelled, up to 5 suggestions appear at the top of the menu above a separator, followed by the standard editor context menu (cut, copy, paste, etc.). Clicking a suggestion replaces the misspelled word via `QTextCursor::insertText()`.

`Tools` > `Check Spelling...` re-runs the highlight pass over the entire document by calling `highlighter_->rehighlight()`.

## Optional Features

### 1. Cursor Line / Column Indicator

**Where:** Status bar at the bottom of the window.

The existing `update_status_bar()` function was extended to read the current cursor position from `editor->textCursor()`. `blockNumber()` returns the zero-based paragraph index (converted to a 1-based line number), and `columnNumber()` returns the zero-based column (converted to 1-based). The status bar now shows: `Words: N  Lines: N  |  Ln N, Col N`.

The `cursorPositionChanged` signal of `QTextEdit` is connected to `update_status_bar()` so the indicator updates on every cursor movement.

### 2. Font Dialog

**Where:** `Format` > `Font...`

`QFontDialog::getFont()` opens the system font picker pre-populated with the editor's current font. If the user confirms, the selected `QFont` is wrapped in a `QTextCharFormat` and applied to the current selection via `editor->mergeCurrentCharFormat()`. If the user cancels, the `ok` flag is `false` and nothing changes. `mergeCurrentCharFormat` is used instead of `setCurrentCharFormat` to preserve other formatting properties such as bold or italic.

### 3. Text Color

**Where:** `Format` > `Text Color...`

`QColorDialog::getColor()` opens the system color picker pre-populated with the editor's current text color. If the user confirms, `color.isValid()` is `true` and the color is applied to the selection via `QTextCharFormat::setForeground()`. Cancelling the dialog leaves the text unchanged.

### 4. Zoom

**Where:** `View` > `Zoom In` (`Ctrl++` / `Ctrl+=`) / `Zoom Out` (`Ctrl+-`) / `Reset Zoom` (`Ctrl+0`)

`QTextEdit` provides built-in `zoomIn(int range)` and `zoomOut(int range)` methods that increase or decrease the font size by the given number of points. A `zoom_level_` counter tracks the cumulative offset from the base size so that `Reset Zoom` can apply the exact inverse: if `zoom_level_ > 0`, call `zoomOut(zoom_level_)`; if `zoom_level_ < 0`, call `zoomIn(-zoom_level_)`. `Zoom In` is mapped to both `Ctrl++` and `Ctrl+=` to handle keyboards where `+` requires the Shift key.
